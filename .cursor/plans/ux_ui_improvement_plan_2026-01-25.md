# UX/UI 개선 플랜
**Date: 2026-01-25**
**Goal: 사용자 친화적인 인터페이스로 개선**

## 🎯 개선 목표

1. **명확한 정보 하이라키**: 중요 정보가 먼저 보이도록
2. **컨텍스트 안내**: 팝업/바텀시트로 사용자 가이드 제공
3. **데이터 소스 상태 통합**: 워크스페이스와 데이터 소스 연동 상태를 한눈에
4. **노션 스타일 사이드바**: 워크스페이스 클릭 시 오른쪽에서 에이전트 채팅 표시

---

## 📊 현재 문제점 분석

### 1. 프로젝트 오버뷰 페이지 (`/projects/[pid]`)

**문제점**:
- ❌ 데이터 소스 정보가 하단에 분산되어 있음
- ❌ 워크스페이스 상태가 별도 페이지로 이동해야 확인 가능
- ❌ 설정 단계와 Ready 상태의 UI 일관성 부족
- ❌ 데이터 소스 연결 상태가 명확하지 않음
- ❌ 첫 방문 사용자를 위한 안내 부족

**개선 방향**:
- ✅ 상단에 데이터 소스 상태 요약 카드 (GA4/CSV 연결 상태)
- ✅ 워크스페이스 목록을 메인 영역에 통합
- ✅ 각 워크스페이스에 연결된 데이터 소스 표시
- ✅ 첫 방문 시 온보딩 바텀시트

### 2. 워크스페이스 목록 페이지 (`/projects/[pid]/workspaces`)

**문제점**:
- ❌ 워크스페이스 클릭 시 전체 페이지 전환 (컨텍스트 손실)
- ❌ 데이터 소스 연결 상태가 표시되지 않음
- ❌ 워크스페이스별 최근 활동/리포트 미표시
- ❌ 빠른 액션 버튼 부족

**개선 방향**:
- ✅ 워크스페이스 클릭 시 오른쪽 사이드바로 에이전트 채팅 표시
- ✅ 워크스페이스 카드에 데이터 소스 아이콘 표시
- ✅ 최근 리포트/활동 미리보기
- ✅ 호버 시 빠른 액션 메뉴

### 3. 에이전트 페이지 (`/projects/[pid]/workspaces/[wid]/agent`)

**문제점**:
- ❌ 전체 페이지를 차지하여 다른 정보 확인 불가
- ❌ 워크스페이스 목록과 분리되어 있음
- ❌ 데이터 소스 상태 확인 불가

**개선 방향**:
- ✅ 오른쪽 사이드바로 전환 (노션 스타일)
- ✅ 메인 페이지는 프로젝트 오버뷰 유지
- ✅ 사이드바 헤더에 데이터 소스 상태 표시

## 🛠️ 구현 계획

### Phase 1: 공통 컴포넌트 생성

#### 1.1 SlideOver (사이드바) 컴포넌트
- **파일**: `src/shared/ui/SlideOver.tsx`
- **기능**:
  - 오른쪽에서 슬라이드 인/아웃
  - 배경 오버레이 (클릭 시 닫기)
  - 반응형 (모바일: 전체 화면, 데스크톱: 사이드바)
  - 애니메이션 (framer-motion)

#### 1.2 BottomSheet 컴포넌트
- **파일**: `src/shared/ui/BottomSheet.tsx`
- **기능**:
  - 하단에서 슬라이드 업
  - 온보딩/안내용
  - 드래그로 닫기
  - 모바일 최적화

#### 1.3 DataSourceBadge 컴포넌트
- **파일**: `src/shared/ui/DataSourceBadge.tsx`
- **기능**:
  - GA4/CSV 연결 상태 표시
  - 아이콘 + 상태 텍스트
  - 작은 크기로 여러 곳에 사용

#### 1.4 StatusCard 컴포넌트
- **파일**: `src/shared/ui/StatusCard.tsx`
- **기능**:
  - 데이터 소스 상태 요약 카드
  - 연결 상태, 데이터셋 수 등 표시
  - 클릭 시 상세 페이지로 이동

### Phase 2: 프로젝트 오버뷰 페이지 개선

#### 2.1 데이터 소스 상태 통합
- 상단에 StatusCard 그리드 추가
- GA4/CSV 연결 상태를 한눈에 확인
- 연결되지 않은 소스는 "연결하기" CTA

#### 2.2 워크스페이스 목록 통합
- 메인 영역에 워크스페이스 그리드 표시
- 각 카드에 DataSourceBadge 표시
- 클릭 시 SlideOver로 에이전트 채팅 열기

#### 2.3 온보딩 바텀시트
- 첫 방문 시 자동 표시
- 프로젝트 설정 가이드
- "다시 보지 않기" 옵션

### Phase 3: 워크스페이스 페이지 개선

#### 3.1 SlideOver 통합
- 워크스페이스 클릭 시 사이드바 열기
- 메인 페이지는 프로젝트 오버뷰 유지
- URL은 쿼리 파라미터로 관리 (`?workspace=xxx`)

#### 3.2 워크스페이스 카드 개선
- 데이터 소스 아이콘 표시
- 최근 리포트 미리보기
- 호버 시 빠른 액션 메뉴

### Phase 4: 에이전트 채팅 사이드바

#### 4.1 SlideOver 내부 레이아웃
- 헤더: 워크스페이스 정보 + 데이터 소스 상태
- 본문: 채팅 UI (기존 AgentPage 컴포넌트 재사용)
- 푸터: 입력창

#### 4.2 상태 표시
- 데이터 소스 연결 상태
- 데이터 마지막 업데이트 시간
- 분석 가능 여부

## 📐 디자인 시스템

### 사이드바 크기
- **데스크톱**: 480px (고정)
- **태블릿**: 400px
- **모바일**: 전체 화면 (100vw)

### 애니메이션
- **SlideOver 열기**: 300ms ease-out
- **SlideOver 닫기**: 250ms ease-in
- **BottomSheet**: 350ms spring

### 색상 시스템
- **데이터 소스 연결됨**: `success` (녹색)
- **데이터 소스 미연결**: `muted` (회색)
- **경고 상태**: `warning` (노란색)
- **에러 상태**: `danger` (빨간색)

### 타이포그래피
- **페이지 제목**: `text-2xl font-bold`
- **섹션 제목**: `text-lg font-semibold`
- **카드 제목**: `text-base font-medium`
- **상태 텍스트**: `text-sm`

## 🎯 사용자 플로우

### 플로우 1: 프로젝트 첫 방문
```
1. 프로젝트 오버뷰 페이지 진입
   ↓
2. 온보딩 바텀시트 자동 표시
   "프로젝트 설정을 시작하세요"
   ↓
3. 데이터 소스 연결 안내
   "GA4 또는 CSV를 연결하세요"
   ↓
4. 워크스페이스 생성 안내
   "목적별 워크스페이스를 만들어보세요"
```

### 플로우 2: 워크스페이스 분석 시작
```
1. 프로젝트 오버뷰에서 워크스페이스 카드 확인
   [데이터 소스 상태 표시]
   ↓
2. 워크스페이스 카드 클릭
   ↓
3. 오른쪽 사이드바로 에이전트 채팅 열림
   [메인 페이지는 유지]
   ↓
4. 채팅 시작
   "이번 주 가장 큰 변화는?"
   ↓
5. 분석 결과 확인
   [사이드바 내에서 스크롤]
```

### 플로우 3: 데이터 소스 관리
```
1. 프로젝트 오버뷰에서 데이터 소스 상태 카드 확인
   [GA4] ✅ 연결됨 | [CSV] ⚠️ 미연결
   ↓
2. 미연결 소스 클릭
   ↓
3. 연결 페이지로 이동
   (또는 모달로 연결)
```

## 🔧 기술 스펙

### 컴포넌트 구조

```
src/shared/ui/
├── SlideOver.tsx          # 사이드바 컴포넌트
├── BottomSheet.tsx        # 바텀시트 컴포넌트
├── DataSourceBadge.tsx    # 데이터 소스 뱃지
├── StatusCard.tsx         # 상태 카드
└── WorkspaceCard.tsx      # 워크스페이스 카드 (개선)

src/app/(app)/projects/[pid]/
├── page.tsx               # 프로젝트 오버뷰 (개선)
├── components/
│   ├── DataSourceStatus.tsx    # 데이터 소스 상태 섹션
│   ├── WorkspaceGrid.tsx       # 워크스페이스 그리드
│   ├── OnboardingBottomSheet.tsx  # 온보딩 바텀시트
│   └── AgentSlideOver.tsx      # 에이전트 사이드바
```

### 상태 관리

```typescript
// URL 쿼리 파라미터로 사이드바 상태 관리
// ?workspace=xxx → 사이드바 열림
// 없음 → 사이드바 닫힘

// 로컬 스토리지로 온보딩 상태 관리
localStorage.setItem('onboarding_completed', 'true')
```

### 반응형 브레이크포인트

- **모바일** (< 768px): 사이드바 = 전체 화면
- **태블릿** (768px - 1024px): 사이드바 = 400px
- **데스크톱** (> 1024px): 사이드바 = 480px
