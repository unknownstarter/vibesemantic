# 고객 경험 최적화 분석 및 개선 제안
**Date: 2026-01-25**
**Focus: 데이터 연동 후 즉시 만족스러운 결과 제공**

## 🎯 핵심 목표

> **"고객이 데이터(GA4, CSV 등)를 연동했을 때 만족할 만한 결과와 에이전트 경험을 제공"**

---

## 🔍 현재 문제점 분석

### 1. **워크스페이스 클릭 → 에이전트 대화까지의 지연**

**현재 플로우:**
```
1. 워크스페이스 클릭
   ↓ (즉시)
2. 사이드바 열림 (UI만)
   ↓ (네트워크 요청)
3. 워크스페이스 데이터 페칭 (~200ms)
   ↓ (조건 확인)
4. 캐시된 리포트 확인 (~200ms)
   ↓ (캐시 없으면)
5. 리포트 생성 시작
   ↓ (데이터 조회: ~500ms)
6. LangGraph 실행 (~3-10초)
   ↓
7. 리포트 표시
```

**문제점:**
- ❌ 순차적 로딩으로 총 대기 시간: **4-11초**
- ❌ 사용자는 빈 화면을 보며 기다려야 함
- ❌ 첫 경험이 느리고 답답함

**개선 방향:**
- ✅ 프리페칭: 워크스페이스 호버 시 미리 데이터 로드
- ✅ 병렬 처리: 워크스페이스 + 리포트 캐시 동시 조회
- ✅ 스켈레톤 UI: 로딩 중에도 구조 표시
- ✅ 낙관적 업데이트: 캐시된 데이터 먼저 표시

---

### 2. **리포트 생성 시 과도한 데이터 조회**

**현재 `loadContextAndMartSummary` 분석:**

```typescript
// 5개의 테이블을 순차적으로 조회
1. mart_ga4_metrics (전체 기간)
2. mart_ga4_daily_kpis (전체 기간) - Legacy
3. mart_ga4_channel_daily (전체 기간) - Legacy
4. mart_ga4_top_pages_daily (전체 기간) - Legacy
5. mart_csv_daily_metrics (전체 기간)
```

**문제점:**
- ❌ 5개의 개별 쿼리 (네트워크 왕복 5회)
- ❌ 불필요한 데이터 조회 (legacy 테이블도 조회)
- ❌ 집계 로직이 클라이언트에서 실행 (서버 부하)
- ❌ 모든 데이터를 메모리에 로드 후 집계

**개선 방향:**
- ✅ 단일 쿼리로 통합 (JOIN 또는 뷰 사용)
- ✅ 서버 사이드 집계 (DB에서 집계 후 전달)
- ✅ 필요한 데이터만 조회 (필터링 최적화)
- ✅ 인덱스 최적화

---

### 3. **데이터 연동 후 즉시 사용 불가**

**현재 플로우:**
```
1. GA4/CSV 연동 완료
   ↓
2. 프로젝트 상태: ready
   ↓
3. 사용자가 워크스페이스 클릭
   ↓
4. 리포트 생성 시작 (수동)
   ↓
5. 4-11초 대기
   ↓
6. 결과 확인
```

**문제점:**
- ❌ 연동 완료 후에도 사용자가 수동으로 리포트 생성해야 함
- ❌ 첫 결과를 보기까지 시간 소요
- ❌ "연동 완료! 이제 사용하세요" 메시지만 있고 실제 결과 없음

**개선 방향:**
- ✅ 연동 완료 시 자동으로 첫 리포트 생성 (백그라운드)
- ✅ 연동 완료 페이지에서 즉시 결과 미리보기
- ✅ 워크스페이스가 없으면 자동 생성 + 리포트 생성

---

### 4. **캐싱 전략 부족**

**현재 상태:**
- ✅ 서버 사이드: 리포트 캐시 (DB에 저장)
- ❌ 클라이언트 사이드: 캐싱 없음 (매번 fetch)
- ❌ React Query/SWR 미사용
- ❌ 프리페칭 없음

**문제점:**
- ❌ 같은 데이터를 반복 조회
- ❌ 네트워크 요청 증가
- ❌ 느린 반응 속도

**개선 방향:**
- ✅ React Query 도입 (자동 캐싱, 재시도, 백그라운드 업데이트)
- ✅ 프리페칭: 워크스페이스 목록 로드 시 각 워크스페이스 리포트 프리페칭
- ✅ 스마트 캐싱: 데이터 변경 시에만 무효화

---

### 5. **로딩 상태 UX 부족**

**현재:**
- 단순 스피너만 표시
- 진행률 없음
- 부분 로딩 불가

**개선:**
- 스켈레톤 UI (리포트 구조 미리 표시)
- 진행률 표시 (데이터 조회 → 분석 → 생성)
- 부분 결과 표시 (데이터 조회 완료 시 차트 먼저 표시)

---

### 6. **에이전트 응답 지연**

**현재:**
- 전체 응답 완료까지 대기 (3-10초)
- 스트리밍 없음
- 중간 피드백 없음

**개선:**
- 스트리밍 응답 (점진적 표시)
- 중간 상태 표시 ("데이터 분석 중...", "인사이트 도출 중...")
- 타임아웃 처리 및 부분 결과 표시

## 🚀 구체적 개선 제안

### Priority 1: 즉시 만족스러운 첫 경험 (즉시 구현)

#### 1.1 워크스페이스 프리페칭
```typescript
// 워크스페이스 카드 호버 시 미리 데이터 로드
<WorkspaceCard
  onHover={() => {
    // 미리 워크스페이스 데이터 + 리포트 캐시 조회
    prefetchWorkspaceData(workspace.id)
  }}
/>
```

**효과:**
- 클릭 시 즉시 표시 (0ms 대기)
- 사용자 경험 향상

#### 1.2 병렬 데이터 페칭
```typescript
// 워크스페이스 + 리포트 캐시 동시 조회
const [workspace, cachedReport] = await Promise.all([
  fetchWorkspace(workspaceId),
  fetchCachedReport(workspaceId, range),
])
```

**효과:**
- 순차적: ~400ms → 병렬: ~200ms
- 50% 시간 단축

#### 1.3 스켈레톤 UI
```typescript
// 리포트 로딩 중에도 구조 표시
<SkeletonReport />
```

**효과:**
- 빈 화면 대신 구조 표시
- 인지적 대기 시간 감소

---

### Priority 2: 성능 최적화 (중기)

#### 2.1 데이터 조회 최적화
```sql
-- 단일 쿼리로 통합 (예시)
SELECT 
  date,
  SUM(CASE WHEN metric_name = 'sessions' THEN metric_value ELSE 0 END) as sessions,
  SUM(CASE WHEN metric_name = 'active_users' THEN metric_value ELSE 0 END) as active_users,
  ...
FROM mart_ga4_metrics
WHERE project_id = ? AND date BETWEEN ? AND ?
GROUP BY date
```

**효과:**
- 5개 쿼리 → 1개 쿼리
- 네트워크 왕복 5회 → 1회
- 응답 시간: ~500ms → ~100ms

#### 2.2 React Query 도입
```typescript
// 자동 캐싱, 재시도, 백그라운드 업데이트
const { data, isLoading } = useQuery({
  queryKey: ['workspace', workspaceId],
  queryFn: () => fetchWorkspace(workspaceId),
  staleTime: 5 * 60 * 1000, // 5분
})
```

**효과:**
- 자동 캐싱
- 백그라운드 업데이트
- 재시도 로직

---

### Priority 3: 데이터 연동 후 즉시 만족

#### 3.1 연동 완료 시 자동 리포트 생성
```typescript
// GA4/CSV 연동 완료 후
// 백그라운드에서 첫 워크스페이스 리포트 생성
if (project.setup_status === 'ready' && workspaces.length > 0) {
  generateInitialReport(projectId, workspaces[0].id).catch(console.error)
}
```

**효과:**
- 연동 완료 → 즉시 결과 확인 가능
- 첫 경험 개선

#### 3.2 연동 완료 페이지 개선
```typescript
// 연동 완료 페이지에서 미리보기 표시
<DataSourceStatus 
  onComplete={() => {
    // 자동으로 리포트 생성 시작
    showPreviewReport()
  }}
/>
```

## 📊 예상 개선 효과

```
워크스페이스 클릭 → 리포트 표시: 0-2초 (프리페칭)
데이터 연동 완료 → 결과 확인: 즉시 (자동 생성)
```

**개선율:**
- 첫 경험: **80-100% 시간 단축**

## 💡 핵심 인사이트

### 사용자 여정 관점

**현재:**
```
연동 완료 → "이제 사용하세요" → 워크스페이스 클릭 → 대기 → 결과
         (만족도 낮음)              (답답함)        (만족)
```

**개선 후:**
```
연동 완료 → 즉시 결과 표시 → 워크스페이스 클릭 → 즉시 결과
         (만족도 높음)              (즉시 만족)
```

### 데이터 연동 후 즉시 만족을 위한 핵심:

1. **자동화**: 사용자 액션 없이 결과 생성
2. **프리페칭**: 다음 액션 예측하여 미리 준비
3. **점진적 표시**: 전체 대기 대신 부분 결과 표시
4. **캐싱**: 반복 사용 시 즉시 표시
